# Bluff Bazaar — simulation report

Generated by `python scripts/simulate.py report --games 3000`. Real engine, heuristic bots (see `bluff/sim/bots.py`); seeds start at 1000 and every A/B pair uses identical seeds and line-ups. Bots are diagnostics, not substitutes for human playtests.

Mixed matches: 5 strategies, 4 seats — every 4-strategy subset in every seat rotation, so each strategy plays 80% of games. **Win rate = share of the games it played that it won; ties split evenly** (so the column does not sum to 100%).
